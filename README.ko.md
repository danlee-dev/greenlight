# Greenlight

앱스토어와 구글 플레이 심사를 한 번에 통과하기 위한 도구입니다.

Greenlight는 오픈소스 Claude Code 플러그인입니다. 앱 제출을 추측 게임에서
체크리스트로 바꿉니다. 제출 전에 현재 스토어 가이드라인 기준으로 앱을 전수
점검하고, 실제 앱 화면에서 규격에 맞는 스토어 스크린샷을 생성하며, 콘솔
스크린샷을 일일이 붙여넣지 않고도 제출까지 안내합니다.

영어: [README.md](./README.md) 참고.

## 왜 필요한가

지금 앱 제출은 반복 루프입니다. App Store Connect나 Google Play Console에서
다음을 누르고, 화면을 캡처하고, AI에 붙여넣고, 기다리고, 다시 반복합니다. AI는
로그인된 콘솔을 보지도 못하고 살아있는 가이드라인을 읽지도 못해서, 오래된
정보나 두루뭉술한 단계만 알려줍니다. 그사이 기준은 계속 높아집니다. 2026년
애플은 4.3(b)로 저가치 앱을 더 조였고, 2.5.2로 껍데기 바이브코딩 앱 차단을
시작했으며, 5.1.2(i)로 AI 데이터 공유 고지를 추가했습니다. 구글은 신규 개인
계정에 프로덕션 전 테스터 12명, 14일 클로즈드 테스트를 요구합니다.

Greenlight는 이 루프를 없앱니다. 공식 API를 먼저 쓰고, 그다음으로 사용자가
직접 실행하는 Playwright 스크립트로 살아있는 콘솔 상태에 접근합니다. 스크린샷을
붙여넣을 일이 없습니다.

## 무엇을 하는가

- 제출 전 전수 점검: 애플과 구글 가이드라인 기준 점수를 매기고, 통과 또는 보류
  판정과 함께 정확한 차단 사유와 해결책을 제시합니다.
- 스크린샷 스튜디오: 실제 앱 화면을 캡처해 2026 규격 크기로 스토어 스크린샷과
  피처 그래픽을 만들고, 로케일별 헤드라인을 입힙니다.
- 안내형 제출: API와 fastlane을 먼저 쓰고, 로그인 전용 콘솔 화면은 Playwright
  코파일럿으로 처리합니다.
- 프라이버시 생성기: SDK와 권한을 스캔해 애플 프라이버시 라벨,
  PrivacyInfo.xcprivacy, 구글 데이터 안전성 답변을 만듭니다.
- 로컬 콕핏: 체크리스트, 기기 프레임 안 스크린샷 미리보기, 제출 추적기를 보여주는
  localhost 보드입니다.

## 누구를 위한 것인가

앱은 만들 수 있지만 심사 통과가 느리고 불투명하고 떨어지기 쉬운 인디 개발자,
비개발자 창업자, 바이브코더를 위한 도구입니다. iOS와 안드로이드 모두 지원하고
한국어와 영어를 지원합니다.

## 설치

```
/plugin marketplace add danlee-dev/greenlight
/plugin install greenlight@greenlight
```

## 빠른 시작

```
/greenlight:preflight both     # 전체 통과 또는 보류 점검
/greenlight:screenshots ios    # 실제 화면 기반 규격 스크린샷
/greenlight:privacy            # 프라이버시 라벨 + 데이터 안전성
/greenlight:submit ios         # 붙여넣기 없는 안내형 제출
/greenlight:cockpit            # 로컬 점검 보드 열기
```

## 핵심 기능

- 리젝 해결사: 리젝 사유를 붙여넣으면 해결 계획과 App Review에 보낼 답변 초안을
  만듭니다.
- 래퍼 감지기: 앱이 저가치 4.3(b) / 2.5.2 껍데기로 보일 위험을 경고하고 추가할
  네이티브 가치를 제안합니다.
- 클로즈드 테스트 추적기: 구글 플레이의 테스터 12명, 14일 요건을 테스터 키트와
  카운트다운으로 관리합니다.
- 업데이트 가드레일: 메타데이터와 바이너리를 마지막 승인 버전과 비교해 새로
  위험해진 변경을 출시 전에 잡아냅니다.
